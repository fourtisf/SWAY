# Sway

Every X account gets a public reach score and a creator-key market on **Robinhood Chain**. Fans buy keys on a
bonding curve to enter a creator's room and read holder-only posts. The scoring model is open source.

- Product brief: [docs/CLAUDE_CODE_BRIEF.md](docs/CLAUDE_CODE_BRIEF.md)
- Approved UI and behavior reference: [docs/sway-prototype.html](docs/sway-prototype.html) (open it in a browser)

> **Status:** Phase 1 build for testnet. Contracts are **unaudited**: mainnet (chain 4663) is blocked in the API,
> the workers and the deploy script until an audit report is published.

## Layout

```
apps/web          Next.js 14 (App Router) front end, port of the prototype; mock mode for design review
apps/api          Fastify REST + WebSocket (sessions, X OAuth 2.0, feed, rooms, wallet, tasks, battles…)
apps/workers      indexer (chain → Postgres, reorg-safe), points engine, X jobs, battles, Genesis, ETH/USD
packages/curve    exact wei curve + fee math (mirrors SwayKeys.sol) and the prototype's float quote()
packages/scoring  open scoring model (MIT), points/tiers, Genesis 1/√rank split, battle math
packages/shared   API contract (DTOs, routes, WS + bus messages), formatters, tasks, chain presets, ABIs
packages/db       Prisma schema, migrations, client, local demo seed
packages/x        X API v2 client: PKCE, scoring reads, task checks, battle reads, budget + backoff
contracts/        Foundry: SwayKeys, FanEscrow, SwayStaking, GenesisPass, SwayLaunchpad (+ SwayCreatorToken)
```

## Run it locally

Requirements: Node 22, pnpm 10, PostgreSQL 16, Redis 7, Foundry (`forge`, `anvil`, `cast`).

```bash
git submodule update --init --recursive      # forge-std + OpenZeppelin
pnpm install
cp .env.example .env                          # defaults work for a local stack (DEV_AUTH=1)
createdb sway                                 # or use DATABASE_URL of your choice
pnpm db:deploy && pnpm db:seed                # schema + prototype demo data
bash scripts/deploy-local.sh                  # anvil on :8545, deploys contracts, writes addresses to .env
pnpm --filter @sway/workers seed:chain        # opens demo markets and trades keys on anvil
pnpm dev                                      # web :3000, api :4000, workers (indexer + jobs)
```

Open http://localhost:3000. With `DEV_AUTH=1` the Connect X dialog accepts any handle (like the prototype) and
your dev wallet is funded with 0.75 ETH on the local chain.

Design review without any backend: `NEXT_PUBLIC_API_MOCK=1 pnpm dev:web` runs the web app on the prototype's
in-memory data.

## Tests

```bash
pnpm test                    # every package (curve, scoring, shared, x, api, workers, web)
pnpm test:contracts          # forge test: unit, fuzz, invariants, differential curve vectors
pnpm vectors                 # regenerate contracts/test/vectors/curve.json after changing curve math
pnpm --filter @sway/web e2e  # Playwright (mock mode)
```

- `packages/curve` is the source of truth for UI money math. `contracts/test/CurveVectors.t.sol` replays 160
  quotes generated by it through real `buy`/`sell` calls and requires every amount to match **to the wei**.
- `apps/workers/test/indexer.test.ts` deploys to a throwaway anvil, trades, indexes, checks the mirror against
  `packages/curve`, then forces a reorg and checks the rollback.

## How money moves (SwayKeys)

`price(s) = K·(s+2)²`, `K = 0.0000175 ETH`; cost = area under the curve; 1 key = 100 units, minimum 0.01 key.
Fees on the curve price: creator 6% (escrowed in FanEscrow for unclaimed fan markets), protocol 2% (half
stakers, half treasury; cut 10/25/50/75% by staking level), holders 1% (pro rata to current holders through a
reward-per-unit accumulator), referral 1% (half each to the trader's and the creator's referrer; a missing half
goes to protocol). The creator's first key is minted free at market open and can never be sold. Max 10 keys
per wallet in the first 5 minutes after a market's first trade. Every earning is pulled with `claim()`.

## Deploy

- Contracts: `cd contracts && forge script script/Deploy.s.sol --rpc-url $RPC_URL --private-key … --broadcast`
  with `ADMIN` (multisig behind a timelock), `TREASURY`, `OPERATOR`, `FAN_ADMIN`, `ISSUER`, `LAUNCH_SIGNER`,
  `SWAY_TOKEN`. Addresses land in `contracts/deployments/<chainId>.json`. The admin must `acceptOwnership()`.
- Apps: `pnpm build`, then PM2 runs `apps/api/dist/main.js`, `apps/workers/dist/main.js` and `next start` for
  the web app behind Nginx (TLS; `/api` and `/ws` with websocket upgrade proxied to the API).
